# Validation and reporting

## Structure

Run `python scripts/audit_vsdx.py file.vsdx --simulate-connectors --output audit.json`.
Review errors, warnings and unsupported simulation cases. A zero exit code means only implemented checks found no errors; it is not a Microsoft Visio certification or complete ShapeSheet evaluation.

The audit checks ZIP CRC and duplicates, XML parsing, content-type coverage, internal relationship targets, relationship IDs referenced by XML, page shape IDs, master/style IDs, connection targets and obvious formula errors. It reports foreign/media objects and explicit text/style inventory. Inherited styles, complex formulas and routing behavior may require manual review.

## Content and visual fidelity

Match every reference text block, number, node and connection. For OCR-derived content, inspect ambiguous characters against the source. For edits, compare unchanged shapes and package parts; for reconstruction, compare object inventory and scene relationships.

Render the final .vsdx. If Microsoft Visio is unavailable and LibreOffice is installed, use an isolated profile and output directory:

```bash
soffice -env:UserInstallation=file:///tmp/visio-preview-UNIQUE \
  --headless --convert-to pdf --outdir preview file.vsdx
pdftoppm -png -scale-to 1800 preview/file.pdf preview/page
```

Verify the exported PDF exists, is newly generated, has the expected page count, contains intended text and has plausible bounds. View every rendered page. Check font substitution, missing glyphs, line breaks, overflow, visual density, arrow direction and line endings. A PDF text extraction check cannot replace image inspection.

Missing CJK fonts can leave glyphs visually blank even when PDF extraction returns the expected Chinese text. Resolve the actual font family and installed file, refresh the font cache after installing a licensed font, and rerender in a fresh application process/profile before trusting typography.

Render at useful resolution and judge both full-page hierarchy and readable details. For batch edits, refresh previews and bundles only after the final change; compare archived VSDX bytes with checked individual files.

## Movement simulation

The bundled simulator recognizes only standalone straight-connector formulas generated by native_vsdx.py, proportional connection rows and top-level transforms. It validates cached endpoint positions and transformation formulas, then numerically evaluates scenarios for moving the source, moving the target, resizing, rotation, flips and reversing relative direction. It does not execute ShapeSheet formulas, the Visio glue engine or the route planner.

Report unsupported connectors explicitly. Do not remove or simplify them to make the simulator pass. Extend the evaluator only for clearly understood formulas; never eval() arbitrary formulas from an uploaded document.

Use a separate copy for displacement/resize previews. Do not deliver a deliberately displaced test diagram as the final layout.

## Microsoft Visio interaction

When available, test representative diagonal/vertical/horizontal lines, glued and free endpoints, and all modified connector types:

1. Open with no repair prompt.
2. Select and edit native text and frames.
3. Move source and target shapes separately.
4. Resize the target; rotate/flip/group when relevant.
5. Move a line endpoint to a new attachment point and change native arrow formatting.
6. Save, close, reopen and recheck.

Test a real right-angle connector's routing in Visio instead of extrapolating from a straight-line simulation. Report exactly which application/version and actions were checked. If unavailable, state that actual Microsoft Visio opening/dragging remains untested while delivering the completed artifact and available validation.
